# 墨笔-OS (InkBrush-OS) - IDE本地协同小说写作脚手架 ✒️

> **💡 开发哲学：像写代码一样写小说。**
> 
> `InkBrush-OS` 是一个专为 **IDE 原生环境** 打造的、高可控、极轻量、Git 友好的**本地 AI 小说协同创作脚手架**。它无需任何厚重的 GUI 平台或收费的外部 API，完全依托本地 Markdown 文件夹系统，结合您的 **Antigravity Pro / Cursor / Claude Code** 订阅，即可享受殿堂级的协同创作快感！

## 📂 脚手架组件树

本脚手架类似于软件开发中的 **Scaffolding Starter (脚手架模板)**，提供了小说创作所需的全部“基础设施”：

```text
ai小说框架/
├── .mobi/                    # 墨笔-OS 核心脚手架
│   ├── prompts/              # 底层 AI 写作与重构指令规程（API 协议）
│   │   ├── 01_角色塑造指南.md # 约束 AI 深度还原性格，杜绝性格崩溃与降智
│   │   ├── 02_分幕大纲扩写.md # 指引 AI 黄金叙事比例进行细节拉满扩写
│   │   ├── 03_一致性自检规程.md # 章节后 AI 自动输出静态报告，防战力崩盘
│   │   └── 04_行内局部修改.md # 行内热修改指令，精准打补丁重构
│   ├── templates/            # 脚手架组件模板（代码生成器模板）
│   │   ├── character_card.md # 人物卡模板 (境界、秘密、外貌、执念)
│   │   ├── faction_card.md   # 势力地理卡模板 (风貌、层级、底蕴、冲突)
│   │   └── scene_card.md     # 章节分幕细纲模板 (起、承、转、合)
│   ├── scripts/              # 自动化极简脚本（零依赖，纯 Node.js 实现）
│   │   ├── init.js           # 脚手架新书交互式初始化引导向导
│   │   ├── compile.js        # 编译打包出书脚本 (剔除注释，合并 Markdown)
│   │   ├── preview.js        # 可视化看板生成脚本 (扫描文件生成 预览看板.html)
│   │   └── analyze.js        # 小说静态指标分析器 (字数、登场、线索追踪)
│   ├── preview_template.html # 看板 HTML 模板
│   └── 伏笔线索库.json        # 伏笔与线索管理矩阵
├── package.json              # 脚本运行配置
├── run_build.bat             # 一键自动编译出书与看板生成
└── README.md                 # 您正在阅读的项目说明书
```

## ⚡ 极速开始三步走

如果您是第一次克隆此项目，或者想要开辟一本新书：

### 第一步：初始化新书向导
在项目根目录终端执行以下命令（或直接运行 `npm run init`）：
```bash
npm run init
```
* **向导会引导您输入**：书名、笔名、题材流派（修真玄幻/都市爽文/科幻悬疑/言情轻小说）、文风基调。
* **向导会自动生成**：标准的全局配置文件 `config.json`、`小说总纲.md`、首个主角 `主角_叶凌.md`、第一章细纲 `第001章_细纲.md` 以及第一章正文骨架。

### 第二步：配置与微调大纲
1. 打开 `小说总纲.md`，填入您的核心主线创意与境界设定（内置 Mermaid 图表，您可以通过 VS Code 预览器直观查看）。
2. 打开 `设定集/人物卡/`，调整主角设定。
3. 打开 `大纲集/第一卷_微末崛起/第001章_细纲.md`，在“起承转合”三幕中填入您为这一章构思的冲突走向。

### 第三步：让 AI 原地执笔
1. 在 IDE 中进行 **双分栏（Split Editor）**：
   - **左边屏幕**：打开本章的 `第001章_细纲.md` 和 `主角_叶凌.md`。
   - **右边屏幕**：打开空的 `第001章_正文.md`。
2. 在聊天框（Chat Panel）中艾特 AI（我），输入如下“编译指令”：
   > `Antigravity，读取左侧细纲，开始编译执笔右侧第 1 章正文第一幕。文风硬核修仙，注重环境描写，1200字。`
3. 我将作为您的代笔，读取 Front Matter 中绑定的设定集，直接使用代码替换工具，将生成的精彩正文**实时原地写入**到您右侧的 Markdown 文件中，无需您复制粘贴！

## 🛠️ 热重载行内 Debug 与局部重写

当 AI 执笔完成后，若您发现某一段的情节需要修改或精修，我们提供像**代码热更新**一样的机制：

### 方法一：聊天重写
直接对我说：“*重构正文第 3 自然段，主角的反应不够冷酷，改为直接用掌风将茶杯震碎，震慑全场。*” 我会自动生成并原地无缝替换该段落，平滑衔接前后文。

### 方法二：行内开发注释（极客推荐）
直接在正文 Markdown 文件的对应段落下方，插入一行 HTML 开发注释，例如：
```markdown
<!-- AI修改：让叶凡在这个地方态度更加强硬，直接冷哼一声出手，不要多废话 -->
```
然后在聊天框对我说：“*按注释重构第 1 章正文。*” 我会自动扫描整个文件，识别注释指令，重写对应的段落，并**自动清除此注释标签**，保持文件清爽！

## 📊 一键编译、看板更新与静态分析

本脚手架提供强大的本地编译出书工具，无需起任何后台服务器，零内存占用：

### 1. 一键编译与生成看板 (Build)
在终端运行：
```bash
npm run build
```
或者双击运行根目录下的 `run_build.bat`。系统会自动：
- 扫描 `正文草稿/` 下的所有章节，按顺序合并。
- 剔除所有 AI 写作时的 `<!-- AI修改... -->` 内部开发注释和占位符。
- 自动更新根目录下的 `预览看板.html`！

### 2. 绝美的内置看板预览 (Visual UI)
当运行完编译后，您会看到根目录下生成了 `预览看板.html`。
- **如何预览**：在 VS Code 的文件树中，右键 `预览看板.html`，选择 **“Open in Simple Browser (在内置浏览器中打开)”**。
- 您会直接在 IDE 内部看到一个**暗色玻璃国风拟物化**的动态 Web 看板！它会展示：
  - 全书字数指标、均章字数、伏笔回收率。
  - **人物卡库**与各大角色当前的境界状态。
  - **势力与地理**分布卡片。
  - **大纲集章节细纲树**。
  - **伏笔与线索矩阵**的推进和回收状态。

### 3. 静态指标控制台分析 (Analyze)
在终端运行：
```bash
npm run analyze
```
控制台会以直观的形式打印出当前小说的**静态字数走势、角色出场频率、以及伏笔线索库中各伏笔的详细状态清单**，帮助您严密控制长篇创作逻辑！

## 📦 如何复用此脚手架（Git 复用）

本框架具有极高的普适性与复用性。如果您想在 Git 上将其作为一个通用的脚手架 Starter：

1. **推送到 Git 仓库**：
   在根目录下执行：
   ```bash
   git init
   git add .
   git commit -m "feat: init generic InkBrush-OS novel scaffolding"
   git remote add origin <您的通用Git仓库地址>
   git push -u origin main
   ```
2. **开辟一本新书**：
   以后您想写任何题材的新小说，只需在新的地方克隆此仓库：
   ```bash
   git clone <您的通用Git仓库地址> 新小说项目
   cd 新小说项目
   npm run init
   ```
   即可开启全新的写作项目，**完全零重复构建成本**！
